# Copy (复制)

> 一键复制到剪贴板,带成功反馈。

## 示例

### Basic.vue

```vue
<template>
  <KunCopy text="https://github.com/kungal/kun-ui" name="Copy the URL" />
</template>
```

## Props

| 属性 | 类型 | 默认值 |
| --- | --- | --- |
| `text` * | `string` | — |
| `className` | `string` | `""` |

| `size` | `KunUISize` | `"md"` |
