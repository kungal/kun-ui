# Null (空状态)

> 空状态占位,内置看板娘图片与文案。

## 示例

### Basic.vue

```vue
<template>
  <KunNull />
</template>
```

## Props

| 属性 | 类型 | 默认值 |
| --- | --- | --- |
| `description` | `string` | `"莲说这里什么都没有"` |
| `isShowSticker` | `boolean` | `true` |
| `src` | `string` | `KUN_NULL_IMAGE` |
